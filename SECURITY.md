# Security Policy

## Authorized Use Only

Open Bounty Workbench is for legitimate, authorized security research and remediation.

Do not use this project to attack unauthorized targets, access accounts you do not own, bypass scope, harvest credentials, automate bounty spam, or handle payout credentials.

## Reporting Security Issues In This Project

If you find a vulnerability in Open Bounty Workbench itself, please open a private security advisory if the repository host supports it, or contact the maintainers using the project disclosure address once configured.

Please include:

- Affected version or commit.
- Reproduction steps.
- Impact.
- Minimal proof of concept.
- Suggested remediation if known.

## Maintainer Policy

Maintainers should reject contributions that:

- Add autonomous live exploitation.
- Add report auto-submission.
- Add payout or credential handling.
- Encourage scope bypasses.
- Inflate severity or generate speculative reports.
